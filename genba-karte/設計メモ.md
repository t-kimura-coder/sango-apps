# 現場カルテ（genba-karte）設計メモ

過去の現場の事例を、言葉から引く・現場ごとに「建てた時」と「その後」を並べる・振り返る時に足す、ためのアプリ（iPhone 向け PWA）。
構想と決定の記録は社内側の `事例の辞書\現場カルテ_構想.md`（git 外）。ここには、アプリの作りだけを書く。

## 決まり
- **社内データはアプリ（git・公開先）に載せない**。事例カード・現場名・札の一覧・言い換えは「カルテパック」JSON（kind `genba-karte-pack`、schema 1）で配り、端末の IndexedDB に置く。
- リポジトリに入れてよいのは、仕組み・絵・作りもののデモ（`demo.js`）だけ。
- 現場名（お客様の名前）は、パックに入っている時だけ画面に出る。入っていないパックでは物件の記号で出る。
- 入れた人は役割で残し、名前は残さない。

## 画面（`#/` の後ろで分ける）
| 道 | 画面 |
|---|---|
| `#/` | ホーム：絵・検索・よく引く言葉・できること 4つ・現場一覧（新しい年の 4件）・枚数 |
| `#/hiku` | 事例を引く：言葉から札を拾い、近い順に 20件。すべて／建てた時／その後 で絞る。現場名が合えば現場も出す |
| `#/genba`・`#/genba/<記号>` | 現場一覧／現場のカルテ（建てた時 → その後 のつながり、その後、建てた時） |
| `#/card/<id>` | 事例カード：何が要因で・どうなった・どうした方が良かった、対処・結果・札・出典・確認の印 |
| `#/tasu`・`#/tasu/<記号>/<id>` | そう言えばを足す：振り返る時に思い出した事を入れる（その時の気付きは現場ナビ） |
| `#/taisaku` | 対策の行き先（準備中） |
| `#/settei` | 設定：パックの取り込み、足した物の一覧と書き出し、アプリ本体の更新 |

パックが無い時は、どの道でも「取り込んでください」の画面（設定だけは開ける）。`?demo=1` を付けると、`demo.js` の作りもので動く（端末に保存したパックは読まない）。

## カルテパック（schema 1）
```
{ kind: "genba-karte-pack", schema: 1, version: "20261118-0930", built: "2026-11-18",
  cards: [ { id, 題, 事例の種類, 物件, 場面?, 工程[], 部位[], 症状[], 状況, 原因, 対処, 結果, 次からの手, 費用?, 関連[], Claudeの補足, 出典{}, 確かさ, 確認, 作成 } ],
  bukken: { "<記号>": { 種類, 用途, 地域, 季節 } },
  names: { "<記号>": "<現場名>" },        // 無くてもよい
  lists: { 工程[], 部位[], 症状[] },      // 札の一覧
  alias: { "<言葉>": ["<種>", "<札>"] } } // 言い換え
```
- 作る道具は社内側（`事例の辞書\現場カルテ_試作\build.py`）。`場面` が「アフター」で始まるカードを「その後」、ほかを「建てた時」として扱う。
- **パックを受け取る口は `receivePack()` の1つ**。今はファイル（`importFile`）からだけ。将来、合言葉と窓口（GAS）から受け取る時も、ここへ渡す。

## 引き方（`search`）
- 言葉から札を拾う（`pickTags`）：長い言い換え（4文字以上）を先に拾って言葉から外す → 札の名前（「・」「（）」「：」で分けた 2文字以上の語も）→ 言い換え。
- 点：札の一致 1つ 3点。札が当たったカードに、言い換えの言葉が題・状況にあれば 1点ずつ。入れた言葉がそのまま題・状況にあれば 2点。点の高い順、同点は id 順。
- 社内側の `jirei_lookup.py` と同じ考え方（「そのままあれば 2点」だけアプリで足した）。

## 端末に置く物
- IndexedDB `genba-karte`：`meta`（キー `pack`＝取り込んだパック）、`tasu`（足した物。キーは `uid`＝`local-<時刻>`）。
- localStorage：`gk-role`（最後に選んだ役割）。キーの頭は `gk-`（同じドメインの他のアプリと分ける）。
- 足した物の書き出し：`{ kind: "genba-karte-tasu", schema: 1, exported_at, pack_version, items: [...] }` を JSON でダウンロード。書き出しても端末からは消えない。

## 絵
- `art/`：GPT 作成の透過 webp（`hero`・`tile-*`・`note`・`deco`・`empty`）と、現場ナビと同じ家の絵（`kind-house`・`kind-reform`・`kind-shop`）。元の絵は社内側 `現場カルテ_試作\design\`（git 外）。
- 絵が読めない時は、その絵だけ出さない（`onerror` で消す）。小さい線のアイコンは `app.js` の `P` に SVG で持つ。
- 差し替えたら、`?v=` と `service-worker.js` の `APP_SHELL`・`CACHE_VERSION` を上げる。

## 変えた時にそろえる物
`app.js` の `APP_VERSION`、`index.html` の `?v=`、`service-worker.js` の `APP_SHELL` と `CACHE_VERSION`。テスト `tests/specs/genba-karte.basic.spec.js` が、そろいを見る。

## まだ無い物
