お知らせ

使い方

はじめに（1回だけ）
  1. 右上の歯車から氏名とBoxのアップロード用メールアドレスを登録します。
  2. 「工程」タブの案内から、Boxにあるマニュアル_○○.jsonを取り込みます。取り込んだマニュアルはこのiPhoneの中に保存されます。
  3. 「写真」タブで担当現場を登録します。
マニュアルを見る
  1. ホームか「工程」タブで、基礎〜引渡しの6つから工程を選びます。
  2. 上に並んだ番号を左右にスクロールして項目を選ぶと、概要・ポイント・チェックポイントが出ます。「作業手順」で前後の工程と事前準備、「参考資料」でマニュアル原本のページを見られます。
  3. チェックする現場を選ぶと、チェックポイントにチェックを付けられます。付けた日時と名前が残るので、後から見返せます。その現場にない工程は「この現場ではこの工程はない」で灰色にできます。
  4. 最近見た項目は、ホームの「前回の続き」からすぐ開けます。
  5. 工程名が分からないときは、ホームか「工程」タブの検索欄に、現場で聞いた言葉を入れてください。チェック項目の文章からも探します（ひらがな可）。
現場で写真を撮る
  1. 「写真」タブで現場を選び、今回の工程の撮影を押します。工程マニュアルの画面の「撮る」「写真を撮る」からも撮れます。
  2. 撮るとその場で「現場×工程」に仕分けられます。続けて撮るときはもう1枚撮る。
  3. 標準カメラで撮った写真は、撮影ボタン横の写真マークからまとめて取り込めます。
  4. 写真は2種類あります。報告写真（お客様向け。工程カードの撮影ボタン）と、記録写真（マニュアルが求める写真。工程マニュアルの「写真要」のチェック横のカメラ）。撮る前に色付きのラベルの撮影メモを見てください。
  5. 写真を消すときは、「報告」の写真一覧で写真を長押しして「削除」、まとめて消すときは選んでから下の「削除」。撮影直後の画面の小さい写真をタップしても消せます。
  6. 違う工程で撮ってしまった写真は、「報告」の写真一覧で選んで「工程を変更」（長押しの画面からも変更できます）。
週の報告を送る（金・土曜）
  1. 「報告」タブで現場を選び、報告に使う写真をタップして選びます。長押しで拡大できます。
  2. Boxへ送信を押すと宛先がコピーされるので、メールを選んで宛先に貼り付けて送ります。期間中に工程マニュアルで付けたチェックも一緒に送られ、報告づくりの材料になります。
  3. 送ったら報告済みにします。次の報告は翌日からの写真になります。休工で間が空いても、前回の報告の翌日から自動でまとまります。
データについて
  • 写真とマニュアルは、このiPhoneの中だけに保存されます。機種変更に備えて、設定の「バックアップ」で書き出しておけます。
  • 容量が気になったら、「写真」タブの現場画面にある過去の報告から、送った写真を削除してください。
