お知らせ

使い方

はじめに（1回だけ）
  1. 右上の歯車（設定）で氏名を登録し、Boxにあるマニュアル_○○.jsonを取り込みます。マニュアルはこのiPhoneの中に保存されます。
  2. ホームの「担当現場」の＋ 現場を追加から、現場名・工事番号（経理の番号）・担当者を登録します。二人で担当する現場は、全員が同じ工事番号を入れてください。
  3. 途中から担当する現場は、「記録を始めた段階」を選びます。それより前は「導入前」として数えません。
言葉について
  • 段階：基礎・上棟・外装・内装・設備・引渡しの6つ。
  • 工程：段階を細かく分けた17の分類（報告写真はこの単位でまとめます）。
  • 項目：マニュアルの1ページずつ（チェックポイントが並ぶ単位）。
現場で使う
  1. ホームには担当現場が全部並び、今どの段階かが分かります。いちばん上が「今の現場」で、押すと今の段階のマニュアルが開きます。ほかの現場を押すと、そちらが今の現場になります。
  2. やることには、上司からの返信・報告の期限・撮り忘れの品質写真など、その時に必要なものだけが出ます。行の頭に、どの現場の話か（全体の話か）が出ます。次に見る項目から、続きと次の項目をすぐ開けます。工程の段階を開くと、その段階で最後に見ていた項目が開きます。
  3. 「工程」タブで段階を選び、上に並んだ項目を左右にスクロールして選びます。チェックを付けると、日時と名前が残ります。その現場にない項目は、項目名の右の該当なしで外せます。
  4. 気づき・疑問メモの「メモを書く」から、気づいたこと・疑問・職人さんの要望を残せます。疑問は上司に届き、返信が来るとメモの下に出ます。
  5. 項目名が分からない時は、検索欄に現場で聞いた言葉を入れてください（ひらがな可）。
写真を撮る
  1. 品質写真（緑）：工程マニュアルの「写真要」のチェック横のカメラから。撮るとチェックも自動で付きます。1つのチェックに何枚でも残せます（2枚以上は枚数が出て、押すと一覧から追加・削除）。この現場で撮らなくてよいものは、カメラから「撮影不要」を選びます。
  2. 報告写真（木の色・お客様向け）：工程マニュアルの右上の「報告写真」か、報告タブの工程ページから。ゴミ・工具が写らないように。
  3. 写真が足りているかは、写真タブや工程タブの写真要の一覧で確かめられます（全部の段階が1ページに並びます）。
  4. 写真タブでは、写真を選んで「送る写真に入れる」「工程で仕分け」「保存」「削除」ができます。指で横になぞると、まとめて選べます。
週の報告を送る
  1. 月〜土の工事を、金曜〜翌週の月曜（遅くとも火曜）に送ります。月・火曜は、先週の分がまだなら先週の分が出ます。
  2. 「報告」タブで工程を開き、送る写真を選びます（「全部選ぶ」や、指でなぞってまとめて選べます）。
  3. 工程のページの今週のこの工程で「完了・一部完了・作業中」と一言を入れると、お客様への報告メールの材料になります（任意）。送信の画面では「写真以外で今週やったこと」「来週の予定・お客様への連絡」と、上司へのメモを分けて書けます。書きかけは残るので、金〜月に分けて書いても大丈夫です。
  4. Boxへ送信を押すと宛先がコピーされるので、メールを選び、宛先に貼り付けて送ります。「送れましたか？」でOKを押すと、送った写真が報告済みになります（選ばなかった写真は次の報告に残ります）。
  5. PC（Edge・Chrome）で開いた時は、共有画面の代わりに Box Drive の「社内報告」フォルダへ直接保存します（初回だけフォルダを選びます）。
  6. アプリの外で報告した週や、自分は担当しない週は、「報告済みにする」でアプリ外で報告した・今週は報告なしを選びます。上司にもその場で知らせられます。
現場を休む・終える
  1. 休工：ホームの今の現場のカード右上の「休工」から。休工中は報告の遅れに数えません。再開する時は同じボタンです。
  2. 完工：「現場の管理」の「完工にする」から。上司に知らせてから完工になります。
  3. 写真を片付ける：「現場の管理」から。その現場の写真をバックアップに書き出してから、写真のデータだけ消します（チェック・メモの記録は残ります）。写真を見る時は、そのバックアップを設定から戻します。
  4. 上司への知らせ（休工・再開・完工・報告なしの週）は、報告と同じBoxに小さなファイルで送ります。
データについて
  • 写真とマニュアルは、このiPhoneの中だけに保存されます。機種変更や故障に備えて、設定の「バックアップ」で写真も含めて書き出しておいてください。
  • 使っている容量は、設定の「保存容量」で現場ごとに見られます。写真1枚は約0.35MBです。
  • 上司からの返信は、ホームの「やること」か設定の「上司からの返信」から取り込みます。
