# 山郷サポート 管理者ビューア 設計メモ

## 位置づけ（2026-10-04 本人合意）
- 山郷サポート（リーダー用スマホアプリ `sango-support`）で「報告」された症例を、管理者がまとめて見て整理するPC用ビューア
- 管理者は**山郷側1人（PC1台）**が編集、木村（本社）は**閲覧のみ**。金額・原因などの整理は管理者が書き足す。返信はLINE（アプリには返信機能なし）
- 現場ナビ 見守り（`genba-viewer`）と同じ作り：PCのEdge/Chromeで、Box Driveの受け取りフォルダを `showDirectoryPicker` で選んで読む。フォルダのハンドルはIndexedDB `sango-admin` に残し、次回は「読み直す」だけ

## 読むもの（フォルダ内を再帰的に）
- `kind: "sango-support-records"`（リーダーの報告。sender＝担当リーダー、records[] に id・building・category・what・how・vendor・reporter・created_at・updated_at・photos[file]）。同じ id が複数あれば updated_at が新しい方（再送対応）
- 写真：ファイル名で records の photos[].file と結びつける
- `kind: "sango-support-admin"`（`管理データ.json`）：管理者が書き足した内容 `items[id] = {amount, cause, memo, status:"done", at, by}`。編集は**このファイル1つだけ**に書く。保存時にフォルダの最新を読み、同じ症例は新しい方を残して合流してから書く
- `kind: "sango-support-past"`（過去履歴.json）：過去の事例（records[] に amount, cause を持てる）。画面では「過去」ラベル。作成は社内側の `RAG（ナレッジ）/sango_after_ver2/tools/build_past.py`（旧 `sango_after.csv` 74件→`admin_pack/過去履歴.json`＋確認用`過去履歴_分類確認.csv`。年は5〜12月＝2025／1〜4月＝2026、分類は工事内容のことばで振り分け、金額＝業者見積額（同じ作業を頼む／自分たちでやる時の目安）。見積が無く自社で対応した作業は、メモに「自社で対応（作業◯時間）」。請求額・原価・粗利などは載せない）。作成済みで、管理者ビューアでの読み込みも確認済み

## 画面
- 症例一覧（左：建物・分類・担当リーダー・期間・未整理だけ／中央：一覧／右：選んだ症例のプレビュー）。新しい症例／過去の切替、検索（ヘッダ）、新しい順・古い順。ダブルクリックか「詳細を見る」で詳細へ
- 詳細：内容・写真・「管理者による整理」（金額・原因の分類・メモ・整理済みにする）・似た症例（同じ建物×分類、無ければ同じ分類）
- まとめ：件数カード、建物×分類のヒートマップ、分類別・業者別・月別、期間切替、**CSV書き出し**（Excelで開ける、BOM付きUTF-8）
- 設定：フォルダ選択・読み直し・デモ・編集モード（チェックを入れたPCだけ編集可。既定は閲覧専用）・編集者名
- 状態は「未整理／整理済み」の2つ（過去は「過去」）。原因の分類：経年劣化・施工不良・使い方・自然災害・不明・その他（app.js の CAUSES）
- フォルダを選べないブラウザ用に、`<input webkitdirectory>` での読み込み（閲覧のみ。整理内容はファイルのダウンロード）も用意
- デモ（demo.js）は架空データ。実データではない

## 注意
- 社内データ（症例・写真・管理データ）はアプリ・gitに含めない。公開されるのは仕組みと絵（建物・分類のイラスト）だけ
- 編集できるPCは1台だけにする（Box Driveの同期競合を避けるため）
- 更新ルール：app.js / style.css を変えたら index.html の `?v=` と service-worker.js の `APP_SHELL`・`CACHE_VERSION` も合わせる

## 一覧とプレビューの幅（2026-10-05 v5）
- 一覧の右のプレビューは開閉できる（ボタン「プレビューを閉じる／開く」、設定は localStorage `sango-admin-pv`）。既定は、画面幅1500px以上で開く／未満で閉じる。閉じている時は、行を押すとそのまま詳細へ移動する（開いている時は、プレビューを更新し、ダブルクリックで詳細）
- 「何が起きたか」の列が余った幅を使い、長い文章は省略表示（…）。左のメニューは230px

## 症例の非表示（2026-10-05 v6）
- 編集モードの詳細画面に「この症例を非表示にする／非表示を解除する」。管理データの `items[id].hidden = true` に記録するだけで、Box上の元ファイル（報告のJSON・写真）は消えない。テスト案件や誤送信の症例を隠す用途
- 非表示の症例は、一覧（既定）・左の件数・まとめ・CSV・似た症例・未整理の数から除く。一覧の左下に「非表示の症例も表示（N件）」が出て、チェックすると薄く「非表示」の印で出る。解除は詳細から
- 閲覧専用のPC（木村）でも、管理データを読み直せば同じく非表示になる（印は見える）

## まとめの「新規／過去」切り替え（2026-10-05 v7）
- まとめ画面の右上に「すべて／新規のみ／過去のみ」。件数カード・建物×分類・分類別・業者別・月別・CSVが、選んだ範囲で集計される。「過去のみ」を選ぶと期間は自動で「すべての期間」に切り替わる（過去は古い日付のため）。一覧の「すべて／新しい症例／過去」切り替えと同じ考え方
